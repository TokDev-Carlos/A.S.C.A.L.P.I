# CJL System — Operação Base 5

Entrada pública: `CJL.exe`. Atualizações do Mestre usam exclusivamente worker externo. O menu administrativo agenda a atualização e encerra o Bootstrap antes da escrita em Host/raiz. `MAINTENANCE_ENTER` bloqueia novas operações para intervenções críticas; `MAINTENANCE_EXIT` libera a operação após validação.
