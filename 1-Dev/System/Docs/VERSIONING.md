# CJL Versioning

Esta camada de acesso não possui autoridade própria de versão. A versão pública
corrente é lida de `/cjl/Sistema_Dev/VERSION` no WSL Ubuntu-24.04 pelo provedor
compartilhado `App/Core/version.py`.

A versão pública segue `BA.ES.IN.SE`. Campos de compatibilidade presentes em
metadados gerados não constituem autoridades independentes.
