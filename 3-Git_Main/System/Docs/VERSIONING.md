# CJL Versioning

A versão pública corrente é lida de `System/VERSION`, autoridade única deste
sistema Windows. A representação core de compatibilidade é derivada em tempo de
execução pelo provedor compartilhado `App/Core/version.py`.

A versão pública segue `BA.ES.IN.SE`. Campos de compatibilidade presentes em
metadados gerados não constituem autoridades independentes.
