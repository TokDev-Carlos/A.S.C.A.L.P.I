# CJL System — Remote Command Contract v1

Comandos: Status, Open, Focus, Close, Probe, Result, Validate, Health, MaintenanceEnter, MaintenanceExit, UpdateStatus. Transporte: Tailscale + OpenSSH. Sem novo listener, sem credenciais embutidas e sem execução arbitrária. Ações de janela são executadas na sessão interativa pelo Broker do Task Scheduler com RunLevel Limited.
